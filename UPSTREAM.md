# Upstream and Attribution

## Relationship to Seanime

WeebHub OBS Integration is maintained by BiniFn as an integration component for [WeebHub](https://github.com/BiniFn/WeebHub). WeebHub is a modified fork of [Seanime](https://github.com/5rahim/seanime) by 5rahim and contributors.

This repository contains WeebHub-specific OBS bridge code. It does not claim Seanime's upstream media-server implementation as original work. The WeebHub server and its required upstream copyright and GPL-3.0 notices remain the authoritative source for the Seanime-derived functionality.
